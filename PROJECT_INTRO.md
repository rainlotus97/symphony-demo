# Symphony Demo

Symphony Demo is a lightweight static website created to demonstrate Symphony's autonomous coding workflow. It provides a small, dependency-free project that is easy to inspect, run, and extend.

## What It Demonstrates

- A semantic HTML5 page structure
- Styling kept in a dedicated CSS file
- Browser-side behavior implemented with plain JavaScript
- A simple workflow-friendly repository with no build step

## Technology

The project uses standard web technologies:

- HTML5
- CSS3
- JavaScript

There are no external dependencies or frameworks.

## Project Structure

- `index.html` contains the page markup.
- `style.css` contains the visual styles.
- `app.js` contains the client-side behavior.

## Running the Project

Because this is a static site, no installation or build process is required. Open `index.html` directly in a modern web browser to view the demo.

## Purpose

The project is intentionally small so that automated coding agents can make focused changes quickly while preserving a clear and understandable codebase.
